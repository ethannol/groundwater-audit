# Unseen task templates for the human-time protocol

These are deliberately not the six evaluation tasks. Each pair applies the
same operation to a different slice of the same snapshot.

| Pair | Member 1 | Member 2 |
|---|---|---|
| 1. Profile | Nitrate+nitrite (code 00631): rows, wells, non-detects, limit range by year | Total-fraction nitrate (code 00620): the same |
| 2. Comparability | Build a comparable arsenic table and explain the total-fraction rows | Build a comparable nitrate+nitrite table and explain the method change (CL048 vs RED01) |
| 3. Cohort change | Arsenic, periods 2000–2008 vs 2009–2023, last sample per period | Nitrate as N, periods 2000–2008 vs 2009–2023 |
| 4. Uncertainty memo | Share of arsenic cohort wells above 10 µg/L in each period, with an interval | Share of nitrate cohort wells above 10 mg/L as N in each period, with an interval |
