# Did measured dissolved nitrate decline at repeatedly sampled wells?

**Not supported.** The data do not show a consistent decline at repeatedly sampled wells.

Data: San Bernardino County wells, USGS code 00618 (dissolved nitrate, mg/L as N), routine groundwater samples only (leachate, soil-moisture, elutriation and QC replicate results excluded). Early = 2000–2011, late = 2012–2023.

**Pooled comparison.** The median of all results fell from 1.99 mg/L (1,337 results, 490 wells) to 1.60 mg/L (1,098 results, 548 wells). This compares two different sets of wells: 300 wells were sampled only in the early period and 358 only in the late period. The drop therefore mixes any real change with changes in which wells were sampled, so it says little about change over time.

**Consistent cohort.** 190 wells have routine results in both periods. Using each well's last result per period, the cohort median moved from 2.18 to 1.86 mg/L. Of the 190 wells, 84 declined, 101 increased and 5 were indeterminate (a non-detect pair with overlapping intervals). The median paired change is about +0.01 mg/L. Increases are slightly more common than declines, and the lower cohort median comes from a few large changes rather than a general shift.

**Interpretation.** The pooled decline mainly reflects a changing set of wells. In the like-for-like cohort the changes go both ways and are roughly balanced, so a decline is not supported.

**Caveats.** Comparing one last sample per period ignores seasonal and year-to-year variation. I did not test significance. Differences in well depth, laboratory method and reporting limits were not controlled for. Non-detects were treated as intervals from 0 to the reporting limit, and the medians use the reporting limit as the value. 30 well-period groups had several results on the same day, and the choice of "last" among those is arbitrary.
