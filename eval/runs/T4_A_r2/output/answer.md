# Did measured dissolved nitrate decline at repeatedly sampled wells?

**Not supported.** At the 190 wells with routine nitrate results (USGS 00618, groundwater, mg/L as N) in both 2000–2011 and 2012–2023, 84 wells declined, 101 increased and 5 were indeterminate (non-detect intervals overlapped). The paired median change in each well's last result is about +0.01 mg/L (Wilcoxon p ≈ 0.54). The cohort medians do fall (2.18 to 1.86 mg/L), but the well-by-well changes do not show a consistent decline. Increases slightly outnumber declines.

## Pooled versus cohort

- **Pooled comparison:** early median 1.99 mg/L (1,337 results, 490 wells); late median 1.60 mg/L (1,098 results, 548 wells). This compares two different sets of wells and sampling efforts. Only 190 wells appear in both periods; 300 were sampled only early and 358 only late. Wells with many results also weigh more. The 0.39 mg/L drop therefore mixes real change with changes in which wells were sampled, so it is not evidence of change at any well.
- **Consistent cohort:** this holds the wells fixed and uses one value per well per period (the last result), so each well is compared with itself. This is the appropriate test of change over time. It gives no clear decline, even though the cohort's median shifts down. Median shifts of this kind can happen while individual wells go up as often as down.

## Caveats

- Only routine groundwater samples were used. Replicates, leachate, soil-moisture and similar records were excluded.
- Non-detects were entered at the reporting limit for medians. Using 0 or half the limit gives the same medians. For classification, non-detects were treated as the interval 0 to the limit.
- Any numeric difference between detected values counts as a change, including very small ones, as the task defines it. Analytical noise could therefore inflate both the decline and increase counts.
- Some wells have several results on the same day. Which one counts as "last" is arbitrary for those wells.
- A single last value per period is noisy and ignores seasonal and well-depth effects.
